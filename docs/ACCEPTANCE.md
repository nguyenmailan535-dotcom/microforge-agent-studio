# 最终版验收清单

## 推荐综合场景

使用一个待办事项应用同时验证生成、交互、迭代和持久化：

> 生成一个待办事项应用，支持添加任务、勾选完成、删除任务和筛选状态。

## 1. 初始化

1. 在新的浏览器会话中打开在线 Demo。
2. 输入格式正确的邮箱和可选姓名。
3. 点击“进入工作区”。
4. 预期：进入新建项目页，顶部展示本地身份。

## 2. 初始生成

1. 输入推荐场景并点击“开始构建”。
2. 观察“理解需求 / 生成代码 / 校验结果”状态变化。
3. 预期：最终进入项目工作区；Preview 中展示真正可运行的应用；Spec 和 Code 标签可打开。

## 3. 实际交互

1. 添加两条任务。
2. 勾选其中一条完成。
3. 删除另一条。
4. 切换状态筛选。
5. 预期：每一步立即反映在界面中，没有脚本错误。

## 4. 生成应用的数据持久化

1. 保留至少一条任务并刷新浏览器。
2. 重新打开项目。
3. 预期：项目仍存在，任务内容和完成状态仍保留。

## 5. 多轮修改

在项目修改输入框中提交：

> 增加深色主题切换和任务优先级，同时保留现有任务数据及添加、完成、删除和筛选功能。

预期：

- 进度区展示任务拆分或补丁处理状态；
- 生成新的当前版本；
- 原有数据仍存在；
- 原有交互继续可用；
- 深色主题和优先级功能可操作；
- 可以从版本记录恢复上一版本。

## 6. 项目管理与交付

- 重命名项目后，侧栏和面包屑名称同步更新。
- 导出 HTML 后，可在浏览器独立打开并操作。
- 导出备份后删除项目，再导入备份，项目和运行数据恢复。
- 删除项目需要二次确认，确认后项目及其运行数据消失。

## 7. 异常恢复

1. 在生成过程中断开网络，或在本地移除 `DEEPSEEK_API_KEY`。
2. 预期：界面显示错误原因，保留当前需求，并显示“重新生成”按钮。
3. 恢复网络或密钥后点击“重新生成”。
4. 预期：流程重新开始，旧的有效项目版本不受影响。

## 8. 公开访问

- 使用未登录账号的 Edge InPrivate 或 Chrome Incognito 打开在线链接。
- 预期：无需 ChatGPT 登录即可显示初始化页面。
- 注意：无痕会话关闭后，本地数据会按浏览器规则被清除。
